# The One-Line Laugh

Entry for [The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f) on make.fun.

`main.ts` (Node 22) writes one original funny line — a single sentence of at most 200 characters — to `/output/entry.txt`:

> I bought a plant to prove I could keep something alive, and it died while I was reading an article called 'Plants That Are Impossible to Kill.'

Run it with:

```sh
node --experimental-strip-types main.ts
```
